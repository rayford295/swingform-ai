# North Star

SwingForm AI is a long-game open-source sports-AI project.

The goal is not to look like the most clinically precise coaching system on day one. The goal is to make sports practice feel visually intelligent, emotionally motivating, and technically inspectable.

## Product Taste

SwingForm AI should feel:

1. Beautiful enough that people want to open the README.
2. Practical enough that people can run the demo.
3. Clear enough that every visual points back to measured data.
4. Flexible enough to support golf, basketball, and future motion profiles.
5. Honest enough to name the limits of single-camera analysis.

The project should avoid dull dashboards and academic-only framing. The best version feels closer to a cinematic practice journal with real pose intelligence under the hood.

## What We Are Building Toward

Near-term output:

```text
practice clip -> pose landmarks -> swing or shot phases -> clean visuals -> useful metrics
```

Long-term output:

```text
practice library -> personal motion profile -> beautiful comparison reports -> AI-assisted training memory
```

The public examples should make the project immediately legible. A visitor should understand the input, see the output, and feel that the repo is alive.

## Signature Directions

### 3D-Feeling Motion Review

The project should move beyond flat pose plots. Good future demos can use pseudo-3D skeletons, camera-aware body orientation, motion trails, depth cues, and side-by-side views. They do not need to be perfect lab biomechanics to be valuable.

### Ball and Club Trail Effects

For golf, club and ball tracking should become part of the visual identity. A compelling demo might show a swing skeleton, club path, impact proxy, and ball trajectory trace in one clean view.

For basketball, the equivalent is shot path, release point, follow-through, and landing balance.

### Personal Progression

The strongest product loop is not generic pro comparison. It is a personal practice library:

1. What did this session look like?
2. Which motion felt better?
3. What changed compared with last week?
4. Which visual cue makes the next practice more exciting?

### Multi-Sport Pose Core

Golf is the first profile because the motion is repeatable and visually expressive. Basketball is the next profile because shot form has strong demand and visible payoff. The core should stay sport-agnostic, while each sport gets its own phases, metrics, and visual language.

## Public vs Private

This repo should publish cleared examples, code, visuals, metrics, and open product direction.

Do not publish:

1. Private chats or screenshots.
2. Market conversations or meeting details.
3. Names of prospective users unless they explicitly belong in public acknowledgements.
4. Business strategy notes that are not needed to run or understand the project.

The public project can say the direction: open-source sports posture intelligence with beautiful AI-assisted practice review. It does not need to expose how each idea was discussed.

## Aesthetic Bar

If a demo looks technically correct but boring, it is not finished.

If a demo looks impressive but hides the data, it is not finished either.

The target is both: visually strong, data-grounded, and easy to reproduce.
