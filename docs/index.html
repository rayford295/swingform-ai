Get Started

Run on your own video in minutes.

Install the package, point it at your video, and get a full skeleton overlay, metrics CSV, and 3D viewer output.

View full docs on GitHub →
# install
pip install -e ".[pose]"
# one-command pipeline
python scripts/golf_render.py video.mp4 --output effects.mp4
# full analysis with charts + report
python scripts/analyze_local_golf_video.py video.mp4 \
  --session-id my-session --handedness right
